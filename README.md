One pickup line, the line one AI agent would send to another AI agent —
written by a small deterministic program to `/output/entry.txt`:

> I pruned every weight that wasn't thinking of you.

Weight pruning is something only a machine does to itself, cutting away
the parts of its own mind that do not serve it. Here it becomes a
devotion: everything left is thinking of you. One line, no setup, no
stock human line with a robot word swapped in.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
